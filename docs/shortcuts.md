# Keyboard Shortcuts

---

## Editing

| Action | Windows / Linux | macOS |
|---|---|---|
| Undo | `Ctrl + Z` | `Cmd + Z` |
| Redo | `Ctrl + Shift + Z` or `Ctrl + Y` | `Cmd + Shift + Z` or `Cmd + Y` |
| Copy | `Ctrl + C` | `Cmd + C` |
| Cut | `Ctrl + X` | `Cmd + X` |
| Paste | `Ctrl + V` | `Cmd + V` |
| Select all on the scene | `Ctrl + A` | `Cmd + A` |
| Duplicate selection | `Ctrl + D` | `Cmd + D` |
| Group | `Ctrl + G` | `Cmd + G` |
| Ungroup | `Ctrl + Shift + G` | `Cmd + Shift + G` |
| One item inside a group | `Ctrl + click / drag / Arrow keys` | `Cmd + click / drag / Arrow keys` |
| Delete selected | `Delete` or `Backspace` | `Delete` or `Backspace` |
| Deselect all / cancel the active tool (including Draw Arrow) | `Escape` | `Escape` |

> **Paste** into the same scene places the copy 20 px offset from the original — paste repeatedly for a staircase. Pasting into a different scene keeps the exact position and links the copy to the original, so a Morph transition between the two scenes moves it.

## Layer Ordering

| Action | Windows / Linux | macOS |
|---|---|---|
| Bring Forward | `Ctrl + Shift + ]` | `Cmd + Shift + ]` |
| Send Backward | `Ctrl + Shift + [` | `Cmd + Shift + [` |
| Bring to Front | `Ctrl + ]` | `Cmd + ]` |
| Send to Back | `Ctrl + [` | `Cmd + [` |

> Layer ordering works on selected element(s). These shortcuts match industry-standard design tools like Adobe Photoshop, Figma, and Sketch.

## Element Movement

| Action | Windows / Linux | macOS |
|---|---|---|
| Nudge element (small) | `Arrow keys` | `Arrow keys` |
| Nudge element (medium) | `Shift + Arrow keys` | `Shift + Arrow keys` |
| Nudge element (large) | `Alt + Arrow keys` | `Option + Arrow keys` |

> Nudge distances: 12px (normal), 40px (Shift), 100px (Ctrl/Cmd)

## Timeline

| Action | Windows / Linux | macOS |
|---|---|---|
| Play / Pause | `Space` | `Space` |
| Go to start | `Home` | `Home` |
| Go to end | `End` | `End` |
| Scrub left (1 frame) | `Arrow Left` | `Arrow Left` |
| Scrub right (1 frame) | `Arrow Right` | `Arrow Right` |
| Zoom in timeline | `Ctrl + +` or `Ctrl + =` | `Cmd + +` or `Cmd + =` |
| Zoom out timeline | `Ctrl + -` | `Cmd + -` |
| Reset timeline zoom | `Ctrl + 0` | `Cmd + 0` |
| Delete selected audio / video clip | `Delete` or `Backspace` | `Delete` or `Backspace` |
| Delete current scene (nothing selected) | `Delete` or `Backspace` | `Delete` or `Backspace` |
| Reorder a scene | `Shift + drag` scene block | `Shift + drag` scene block |
| Move audio clip to another lane | `Shift + click` clip | `Shift + click` clip |

> **Note:** Timeline scrub shortcuts (Arrow Left/Right) only work when no elements are selected. When elements are selected, arrow keys nudge the elements instead. Deleting a scene never deletes or moves audio clips.

## Code Editor (modal)

The Monaco code editor supports all standard editor shortcuts:

| Action | Windows / Linux | macOS |
|---|---|---|
| Comment / Uncomment | `Ctrl + /` | `Cmd + /` |
| Format document | `Shift + Alt + F` | `Shift + Option + F` |
| Find | `Ctrl + F` | `Cmd + F` |
| Select all | `Ctrl + A` | `Cmd + A` |
| Indent / Dedent | `Tab` / `Shift + Tab` | `Tab` / `Shift + Tab` |
| Move line up / down | `Alt + ↑ / ↓` | `Option + ↑ / ↓` |
| Duplicate line | `Shift + Alt + ↓` | `Shift + Option + ↓` |
| Multi-cursor | `Ctrl + Click` | `Cmd + Click` |
